# BOTANIQ WELLNESS™

Africa's Botanical Wellness Company — marketing site built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server (webpack)
- `npm run build` — production build
- `npm start` — serve production build

## Routes

| Path | Page |
|------|------|
| `/` | Home — Science Meets Tradition |
| `/about` | About — Rooted in Nature |
| `/what-we-do` | What We Do |
| `/research` | Research programs |
| `/research/community-health` | Community Health Intelligence |
| `/wellness` | Wellness overview |
| `/partner` | Partnerships |
| `/contact` | Contact |
| `/research-hub` | ResearchHub login (placeholder) |
| `/legal` | Legal & Privacy |

## Stack

Next.js 16 · React 19 · Tailwind CSS 4 · Cormorant Garamond + Outfit · Lucide icons
